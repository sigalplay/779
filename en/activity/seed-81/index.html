Exercise Dice

Ages 4–9 15 minutes Easy

Exercise Dice

About This Activity

A movement dice game in which each number represents a different exercise.

Materials
1Die, or cards numbered 1 to 6

Preparation: Choose an exercise for each number and write the list on a sheet if helpful.

How to Play

1Make a key: 1 = jump, 2 = reach up, 3 = touch toes, 4 = turn around, 5 = run on the spot, 6 = star jump.

2Each player rolls the die in turn.

3Everyone completes the matching exercise.

4For a challenge, roll several times, remember the sequence, and complete the exercises in order.

Make it easier: Use only one roll per turn without building a sequence.

Add a challenge: Gradually increase the sequence to five rolls.
