Build a Tower from a Model

Ages 3–9 10 minutes Moderate

Build a Tower from a Model

About This Activity

Show your child a model built from blocks, and have them try to rebuild it exactly.

Materials
1Building blocks or LEGO

Preparation: Build a simple model ahead of time using 3-5 blocks in different colors.

How to Play

1Show your child the finished model for a few seconds.

2Take the model apart (or cover it up).

3Have your child build a matching model from memory or by peeking at the original.

4Compare the two models together at the end.

Make it easier: Start with a model of just 2-3 blocks, and leave it visible during building (no memory required).

Add a challenge: Increase the number of blocks, or require building entirely from memory with no peeking.
