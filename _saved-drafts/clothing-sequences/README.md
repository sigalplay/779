# טיוטות רצפי לבוש — לא מוצגות באתר

התיקייה שומרת את האיורים להמשך עבודה ביום אחר.

- `putting-on-shirt/` — תשעת איורי טיוטת לבישת החולצה.
- `shoelaces/` — כל גרסאות האיורים שנוצרו לעבודה על קשירת שרוכים.
- איורי הכפתורים ואיורי רצף הלבוש הקודם נשארו תחת `public/icon-bank/daily-sequences/`, אך הרצפים שלהם מסומנים כמוסתרים ואינם מוצגים באתר.

כדי להחזיר את תחום הלבוש בעתיד, יש להסיר את הסימון `hidden` מהקטגוריה ומהרצפים הרלוונטיים בקובץ `src/lib/daily-sequences.js`.
